# 映像朝刊

映像生成AI・空間演出（プロジェクションマッピング、イマーシブ展示）・制作ツール・スタジオ／作家の動きと、イベント情報を毎朝まとめる個人用の朝刊です。

- ページ：GitHub Pages（このリポジトリの `main` ブランチ、ルート）
- 毎朝 7:50 ごろ（日本時間）に Claude の定期タスクが調べて、`data/` の JSON を書き足します。

## ファイル

| パス | 中身 |
| --- | --- |
| `index.html` | ページ本体（1ファイル）。`data/` の JSON を読んで表示する |
| `data/guide.md` | 毎朝の調査の書き方の手引き |
| `data/index.json` | 号の一覧（日付・前口上・分野ごとの件数） |
| `data/issues/YYYY-MM-DD.json` | 各日の号 |
| `data/events.json` | イベント一覧 |
| `data/watch.json` | 追うキーワード・エリア・メモ |
| `data/status.json` | 最後に調べた日時 |

## メモ

- 「保存」はページを見ているブラウザ（localStorage）にだけ残ります。
- 写真は各記事・公式ページの画像を直接表示しています。読めないときは分野ごとの図柄に切り替わります。
- 検索エンジンには載せない設定（noindex）にしています。
